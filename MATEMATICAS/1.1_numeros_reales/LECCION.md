# 🧮 Lección 1.1: Los Números Reales y sus Propiedades

## 📝 Resumen del Tema
- **Números Reales:** Todos los números que existen en la recta numérica.
- **Clasificación:**
  - **Naturales:** Para contar objetos enteros (1, 2, 3...).
  - **Enteros:** Naturales, negativos y el cero (-3, -2, -1, 0, 1, 2...).
  - **Racionales:** Fracciones y decimales exactos (1/2, 0.75).
  - **Irracionales:** Decimales infinitos no periódicos (Pi: 3.14159...).
- **Valor Absoluto:** Distancia de un número al cero (siempre positivo).
- **Propiedades:**
  - **Conmutativa:** El orden no altera la suma ni la multiplicación ($a + b = b + a$).
  - **Asociativa:** El agrupar números no cambia el resultado.
  - **Distributiva:** Multiplica al grupo entero.
